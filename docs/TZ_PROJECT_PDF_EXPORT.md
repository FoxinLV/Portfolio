# ТЗ: PDF-каталог выбранных проектов

## Цель

Дать посетителю возможность выбрать несколько проектов на странице «Проекты» и скачать единый презентационный PDF, пригодный для отправки работодателю, заказчику или печати.

## Пользовательский сценарий

1. Пользователь включает режим «PDF-каталог».
2. Отмечает проекты вручную либо выбирает все проекты текущей фильтрации.
3. Видит количество выбранных проектов и может очистить выбор.
4. Нажимает «Скачать PDF» и видит состояние подготовки.
5. Получает файл `Портфолио_проектов_ГГГГ-ММ-ДД.pdf`.

## Состав PDF

- Титульная страница: владелец портфолио, количество проектов, период и дата формирования.
- Каждый проект начинается с новой страницы.
- Название, дата, тип системы, направление, краткое и полное описание.
- Обложка и все доступные изображения галереи.
- Роль, задачи, функции и результаты.
- Связанные компания, должность, период работы, роль в проекте, вклад и ключевые моменты.
- Технологии с названиями и иконками, если иконка доступна.
- Публичные ссылки и перечень файлов.
- Нумерация страниц и подпись о формировании из актуальных данных портфолио.

## Правила данных

- Источник проектов: опубликованные `project.json`.
- Источник компаний и должностей: `career.projectAssignments`.
- Один проект может относиться к нескольким компаниям и должностям.
- Выбор и фильтры не изменяют JSON и не записываются в S3.
- Недоступное изображение пропускается, остальные данные продолжают экспортироваться.
- Дублирующаяся обложка не повторяется в галерее.

## UI/UX

- Режим выбора визуально отделён от обычного просмотра проектов.
- На карточках появляются крупные доступные переключатели выбора.
- Доступны действия: «Выбрать показанные», «Очистить», «Отмена», «Скачать PDF».
- На мобильном панель действий переносится на несколько строк и не перекрывает контент.
- Во время генерации кнопки блокируются и отображается текущий этап подготовки.

## Оформление PDF

- Формат A4, светлая профессиональная стилистика портфолио.
- Основной акцентный цвет сайта, единая типографика и безопасные поля печати.
- Изображения сохраняют пропорции; фотографии подготавливаются как JPEG, прозрачные иконки как PNG.
- Длинные описания, списки и названия переносятся без обрезания.
- Карточки компаний и блоки технологий по возможности не разрываются между страницами.

## Проверка готовности

- Экспорт одного и нескольких проектов.
- Проект без обложки, без галереи, без карьерной связи и без иконок.
- Проект с несколькими компаниями и длинным описанием.
- Кириллица, переносы строк, URL и нумерация страниц.
- Проверка PDF через извлечение текста и рендер страниц в PNG.
